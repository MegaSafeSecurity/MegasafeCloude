# Mega Safe Security Services Sdn Bhd

This is the original FIND scroll-animation layout, converted only at the content level for Mega Safe Security Services Sdn Bhd.

## Unchanged design files

The original layout structure, cloud treatment, 3D scroll animation and typography remain the same. The following files preserve the original design system:

- `styles.css`
- `intro.js`

Only these functional adjustments were made:

- `index.html` — Mega Safe names, details, links and local media.
- `intro.css` — the image-cutout title was reduced so TRUSTED / PROTECTION is centred and fully visible.
- `script.js` — the footer email field opens a quotation email addressed to Mega Safe.

## Open and edit

Open this folder in VS Code, then preview `index.html` in any modern browser. No installation or build command is needed.

## GitHub Pages

Upload the complete folder to a GitHub repository, then enable **Settings → Pages → Deploy from a branch** using the repository root. Keep the `assets` folder with the HTML file because the website uses local paths for the Mega Safe logo, company profile, organisation chart, director photo and media.
